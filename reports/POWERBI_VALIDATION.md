## How each check was done

| Kind of evidence | What it covers |

| **Automatic** (`tests/test_phase5_pbip.py`, 14 tests) | Every report file is valid against Microsoft's published PBIR schemas; 4 pages with the coverage banner; every field a visual uses exists in the model; no overlaps or off-page visuals; the tech table appears only in its own panel; the year slicer filters only the pie; interval charts plot the estimate as a column and the bounds as markers, from source tables with one row per category |
| **Automatic** (`src/phase5_export_bi.py`) | The 14 headline numbers computed from the PostgreSQL views equal a pandas recomputation from `data/processed/` (`powerbi/headline_reconciliation.csv`) |

## Interval charts

| p1 "Events per year with 90% interval" | `bootstrap_yearly.events` | `events_lo`, `events_hi` | notebook 05, 1,000 company-cluster bootstrap replicates | One row per year, so Power BI's Sum returns the stored value; lower ≤ estimate ≤ upper for all 8 years (e.g. 2023: 834 / 885 / 936) |
